# Review Rubric

Use this rubric during end-of-day or end-of-week review.

## Grade Each Trade

### A

- clear 4H dealing range
- clear premium / discount location
- clear liquidity interaction
- PD arrays formed in the right part of the range
- key PD array was respected
- bias made sense
- narrative was clear
- clear 15m MSS
- convincing 5m displacement
- fresh 5m FVG
- valid session / time
- no chasing

### B

- setup mostly matched the model
- one layer was slightly unclear
- still acceptable for paper trading

### C

- execution features appeared, but DRT / bias / narrative / context were not clean enough
- likely a context trade, not a true starter-model trade

### D

- range was unclear
- bias was unclear or price was stuck around equilibrium
- liquidity event was unclear or in the wrong place
- key PD array formed in the wrong place or was clearly disrespected
- no clear 15m MSS
- no clear 5m displacement / FVG
- outside session or poor time of day
- chase entry
- should not have been logged as valid

## Weekly Questions

- Which dealing-range conditions showed up in most winners?
- Which liquidity interaction repeated most in the winners and losers?
- Which PD arrays were respected in the best setups, and which were disrespected in the worst ones?
- Was the narrative clearer on BTC or ETH?
- Did 15m MSS quality differ meaningfully between winners and losers?
- Did late-session entries underperform?
- Did weekend setups underperform?
- Are the invalidation rules too loose or too tight?
